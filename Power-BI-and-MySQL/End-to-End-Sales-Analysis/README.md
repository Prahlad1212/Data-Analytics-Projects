# End-to-End Sales Analysis | MySQL & Power BI

## Project Overview
This project demonstrates an end-to-end data analytics workflow using MySQL and Microsoft Power BI. It focuses on analyzing sales data, extracting meaningful business insights, and presenting findings through an interactive dashboard.

## Tools & Technologies
- MySQL
- Microsoft Power BI
- Power Query
- DAX
- SQL

## Project Workflow

### 1. Data Preparation
- Imported the sales dataset into MySQL.
- Created database tables.
- Structured and organized the data.

### 2. Data Cleaning & Analysis using MySQL
- Identified and handled missing values.
- Removed duplicate records where appropriate.
- Used SQL queries for data transformation.
- Applied joins, aggregations, subqueries, and window functions.

### 3. Power BI Dashboard Development
- Connected MySQL with Power BI.
- Created data models and relationships.
- Developed DAX measures.
- Designed interactive dashboards using charts, KPI cards, and slicers.

## Business Analysis Objectives
- Analyze overall sales performance.
- Identify top-performing products.
- Understand regional sales trends.
- Evaluate revenue and profitability.
- Track monthly sales performance.
