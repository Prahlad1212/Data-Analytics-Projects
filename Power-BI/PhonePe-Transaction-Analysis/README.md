# PhonePe Transaction Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing PhonePe digital payment transactions using Microsoft Power BI. The dashboard presents transaction trends, payment activity, and business insights through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Project Objectives
- Analyze digital payment transaction trends.
- Understand transaction volume and transaction value.
- Identify state-wise and regional transaction patterns.
- Compare transaction performance across different periods.
- Present insights through interactive dashboards.

## Key Dashboard Features
- Interactive KPI cards
- Transaction volume analysis
- Transaction value analysis
- State-wise transaction analysis
- Time-based transaction trends
- Interactive filters and slicers
