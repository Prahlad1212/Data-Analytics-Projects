# E-Commerce Sales Analysis Dashboard | Tableau

## Project Overview
This project focuses on analyzing e-commerce sales data using Tableau to understand sales performance, profitability, product trends, and business performance.

## Tools & Technologies
- Tableau
- Microsoft Excel
- Data Visualization
- Data Analysis

## Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Analyze monthly sales and profit trends.
- Understand city-wise sales performance.
- Compare payment mode performance.

## Dashboard Features
- Interactive visualizations
- Sales by category
- Monthly profit trends
- Profit by category
- Sales by payment mode
- City-wise profit analysis
- Product-level performance analysis
