# HR Analytics Dashboard | Microsoft Excel

## Project Overview
This project focuses on analyzing Human Resources (HR) data using Microsoft Excel to gain insights into employee performance, workforce distribution, ratings, and other HR metrics.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning

## Project Objectives
- Analyze employee distribution and workforce trends.
- Evaluate employee performance and ratings.
- Identify patterns in employee data.
- Present HR metrics through an interactive dashboard.

## Dashboard Features
- Interactive KPI cards
- Employee data analysis
- Performance and rating analysis
- Department-wise analysis
- Interactive slicers and filters
- Dynamic charts and visualizations

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Excel Formulas
- Pivot Tables
- Data Visualization
- Dashboard Development
